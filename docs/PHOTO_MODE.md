# Photo postcards

Camera button / C captures the current rendered view and pauses gameplay. The preview excludes DOM game controls and adds a light footer with the nearby place (or region), game name, domain and fictional-world label. Download is a PNG; optional native file sharing requires a separate player click and browser support. No image uploads occur automatically.

The scene keeps its aspect ratio, with its longest edge capped at 1600 pixels before the footer. Capture explicitly renders and immediately copies the WebGL canvas, avoiding a persistent drawing buffer during normal play. Only the current postcard is retained in memory; closing drops it. The game view includes the player/vehicle. This first version does not add a free camera, zoom or portrait cropping: frame the scene in normal play, then capture.

Validated PNG download against the generated bytes, HUD hiding, C/Escape and resumed movement. Inspected the downloaded scene. Mobile native sharing and device performance remain manual checks in KADAL_PLAYTEST.md. No deployment.
