# First journey pilot

## This batch

1. New players can start directly in the parked jeep or keep the original walking entry. Returning worlds keep their saved location and time. Existing new-world defaults are 08:00 and eight minutes before a weather transition can begin.
2. A dismissible driving-controls card introduces keyboard/touch input. It creates no required objective.
3. Roadside signs point from Kadal toward the harbour, through the inland connection and past Paddy Lane toward the hills. Paddy Lane gains a discoverable market stop and a shaded fieldside resting bench.
4. Pause/Help exposes a selectable local playtest summary. It records active seconds, driving seconds, time to first jeep use, new discoveries and selected route discoveries. At most 20 summaries are stored in this browser. Paused and hidden time is excluded. There are no network requests, player IDs, precise positions or messages. Clearing the summary starts a fresh local measurement without touching the game save.

This is a small tester pilot, not production analytics. Testers must voluntarily send their summary with feedback. Earlier-session count refers to this browser, not unique people or daily retention. A first load that fails before play starts is not counted. Photo mode, return events and deeper scenery work remain later batches.
